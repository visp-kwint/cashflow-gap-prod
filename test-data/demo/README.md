# Демо-выписки (ТЗ-доработка WP-7 §13)

Здесь лежат демо-выписки, которые грузят:

- `npm run seed` — в аккаунт `demo@cashflow.ru` (контракт: docs/api-contract.md);
- кнопка «Использовать демо-данные» (регистрация с `useDemoData`) — в аккаунт нового пользователя;
- `POST /api/demo { company? }` — подгрузка выбранной выписки в текущий аккаунт.

Файлы (CSV формата организаторов, `test-data/README.md`) выбирает `node server/scripts/pick-demo.mjs`
по правилам §13: история ≥ 18 месяцев; виден реальный разрыв при `T = P25` (после честной
калибровки бэктестом, `docs/BACKTEST.md`); виды бизнеса разные (из `companies.csv`).

## Текущее содержимое

| Файл | Откуда |
| --- | --- |
| `statement-demo-C096.csv` | ИП, «Продажи на маркетплейсах» (01.10.2024–30.09.2026, 594 оп.) — активная, свежая (asOf = 2026-09-30) |
| `statement-demo-C097.csv` | ООО, «Производство мебели на заказ» (22.09.2025–30.09.2026, 429 оп.) — активная, свежая |
| `statement-demo-C098.csv` | ИП, «IT-услуги и разработка» (01.10.2024–17.10.2025, 373 оп.) — архивная |

Выписки организаторов (датасет 150 компаний, кросс-чек по `all_operations.csv`), `FORECAST_AS_OF = 2026-09-30` в `server/.env.example`. Seed задаёт демо-учётке порог T = P25-квантиль остатков активной выписки (C096 ≈ 1,74 млн ₽) и плановые события (договор, счёт, налог, просроченный платёж) — на asOf=2026-09-30 на главной виден будущий разрыв.

Датасет организаторов лежит локально в `test-data/statements/` (папка в .gitignore, в репозиторий не коммитится; примеры — `test-data/C001.csv`). Для перебора «своего» состава прогоните `node server/scripts/pick-demo.mjs` (берёт 2–3 выписки разных видов бизнеса с реальным разрывом из `statements/`) и обновите `FORECAST_AS_OF` в `server/.env.example` на последнюю дату новых выписок.
