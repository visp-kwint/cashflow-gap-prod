# Сравнение подходов прогноза (ТЗ-доработка WP-2)

Файлы: statement-demo-C001.csv. Точек оценено: 39 (горизонт 30 дн., шаг 7 дн., период 2026-01-01…2026-09-30, мин. история 90 дн., порог T = P10).
Запуск: 2026-10-25T09:31:38.799Z.

## Методика
- Все подходы прогнозируют от общего cut по общим операциям (≤ cut) и сравниваются с фактом balance_eod (с корректировкой переводов собственных средств) за 30 дней.
- MAE конца горизонта и минимума; skill против наивного (B0 без изменений); MAE дат разрыва (дни, где разрыв зафиксирован и у модели, и в факте), число пропущенных/ложных разрывов; Brier для подходов с вероятностью (правило ≥ 50 %).
- Абляция — полная модель с выключенным одним компонентом; налоговый эксперимент — с/без событий налогового календаря (ТЗ-доп. §4.1 В).

## Ограничения
- Holt-Winters — дефолтные параметры forecast.config.js (подбор на тренировочном периоде не проводился: датасет организаторов не в репозитории). Волна C (аудит §2.1): дефолты переподобраны по абляциям (выводы владельца отключены, окно статистики 3 мес.) — решение и обоснование в forecast.config.js. Вероятности в таблицах — перекалиброванные (изотоническая сетка PAV по бинам калибровки бэктеста, gaps.P25.calibration: 39 точек, 1 факт-разрыв → константа 1/39 ≈ 2,6 %; на P0/P5/P10 факт-разрывов нет, карта дегенеративна). Пересчёт калибровочной карты на датасете организаторов (150 компаний) — план развития.
- Сравнение выполнено на 1 компании (C001, доступный пример CSV); датасет организаторов — 150 компаний, 15 видов бизнеса (test-data/README.md) — в репозиторий не коммитится, ожидается: после подстановки `npm run backtest -- test-data/statements --models all`.
- Абляции однокомпонентные; совместные эффекты компонентов не оцениваются.
