## Методика
- Скользящее начало: прогноз только по операциям ≤ cut; факт — balance_eod за следующие H дней.
- Метрики по остатку (конец горизонта и минимум): MAE, RMSE, bias, skill против наивного (B0 без изменений).
- Пороги T ∈ {0, P5, P10, P25} остатков компании до cut. Brier модели и константного прогноза, P/R/F1 при правиле «предупреждение при вероятности ≥ 50 %», калибровка (бины по 10 п.п.).
- Заблаговременность: дни между cut и датой факт-разрыва для фактов, о которых предупредила модель (медиана и P25).
- Корректировка: переводы собственных средств добавляются/вычитаются из факт-остатка; метрики даны с корректировкой (основные) и без.
- Волна C (аудит §2.1): дефолты forecast.config.js переподобраны по абляциям — ownerWithdrawalsEnabled: false, statsWindowMonths: 3 (решение и обоснование — в комментариях конфига и docs/MODEL_COMPARISON.md); подбора на тренировочном периоде не проводилось (датасет организаторов не в репозитории). Вероятность разрыва перекалибрована: изотоническая сетка PAV по бинам калибровки бэктеста (gaps.P25.calibration: 39 точек, 1 факт-разрыв → константа 1/39 ≈ 2,6 %) — см. calibrateGapProbabilityPct в forecast.service.js.
